TRJ VISUAL GALLERY V1
=====================

CUSTOMER WEBSITE: index.html
ADMIN WEBSITE: admin.html
Default Admin PIN: 5467

START:
1) Double click START_WEBSITE.bat
2) Customer site: http://localhost:8080/index.html
3) Admin site: http://localhost:8080/admin.html (or START_ADMIN.bat after server is running)

PLANS:
FREE: Rs.0, watermark, reduced photo quality, slower download, Help Assistant max 5 questions/day, no folder download.
SILVER: 10 Day Pro Rs.399, no watermark, high quality, fast assistant, NO folder download.
GOLD: 30 Day Pro Rs.649, BEST & RECOMMENDED, no watermark, high quality, fast assistant, whole photo/video folder download.

ADMIN:
Use Google Chrome. Login, then click CONNECT WEBSITE FOLDER and select this TRJ_VISUAL_GALLERY_WEBSITE folder.
You can add/delete/disable promo codes, set Silver/Gold plan and expiry date, edit Help Assistant questions/answers, edit Nature/Wildlife intros, create media folders, upload files, scan media, and save everything back into config.js.

IMPORTANT:
After Admin changes, click SAVE ALL CHANGES TO WEBSITE and refresh customer website.
